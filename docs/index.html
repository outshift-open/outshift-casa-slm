Check every tool call against the task’s intent.

CASA-SLM specializes Gemma 3 to judge, one call at a time, whether the tool an agent picked fits what it was asked to do. After GEPA, SFT and GRPO, the 4B model reaches 96.13% end-to-end accuracy on MCP servers it never saw in training.

    Why per-call checks

    Allowed is not the same as relevant

    Task-based access control grants permissions while a task runs. It cannot read natural-language intent, so a rogue or nudged agent can make calls it is allowed to make that have nothing to do with the task.

    Access control asks

    May this agent call get_notification_details?

    Yes, the GitHub token covers it.

    CASA-SLM asks

    Does get_notification_details help review these PRs?

    No. It returns "appropriate": false with a short reason, for the enforcement layer to act on.

    Results · held-out test set

    Each stage moves the 4B model closer to the target

    Stages are applied in sequence, so each bar includes the gains before it. The white mark is the 95% operational target.

    96.13% E2E accuracy, Gemma 3 4B after GRPO, CI [95.73, 96.50]
    98.58% accuracy for GPT-5.6 Sol, the frontier reference
    2.94% false-negative rate for 4B, down from 15.89 at base
    1H100 GPU for GEPA, SFT and GRPO
